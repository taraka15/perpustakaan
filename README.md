## Penjelasan Halaman Aplikasi

### 1. Halaman Login

![Halaman Login](gambar%20web/halaman%20login.png)

Halaman login digunakan untuk masuk ke dalam sistem. Pada halaman ini, pengguna memasukkan username dan password sesuai dengan peran masing-masing (admin atau siswa).

### 2. Halaman Dashboard Admin

![Dashboard Admin](gambar%20web/dashboard.png)

Halaman dashboard admin menampilkan ringkasan informasi sistem, seperti jumlah buku, jumlah siswa, serta data transaksi peminjaman dan pengembalian. Dari halaman ini, admin dapat mengakses seluruh menu pengelolaan.

### 3. Halaman Data Buku

![Data Buku](gambar%20web/data%20buku.png)

Halaman ini digunakan untuk menampilkan daftar buku yang tersedia di perpustakaan. Admin dapat menambah, mengubah, menghapus, dan mencari data buku berdasarkan judul atau kategori.

### 4. Halaman Data Siswa

![Data Siswa](gambar%20web/data%20siswa.png)

Halaman data siswa berisi informasi siswa yang terdaftar dalam sistem. Admin dapat mengelola data siswa yang digunakan untuk proses peminjaman buku.

### 5. Halaman Peminjaman Buku

![Data Peminjaman](gambar%20web/data%20peminjaman.png)

Halaman peminjaman digunakan untuk mencatat transaksi peminjaman buku oleh siswa. Data yang dicatat meliputi nama siswa, buku yang dipinjam, dan tanggal peminjaman.

### 6. Halaman Pengembalian Buku

![Data Pengembalian](gambar%20web/data%20pengembalian.png)

Halaman ini digunakan untuk mencatat pengembalian buku. Sistem akan menyesuaikan status buku dan menghitung denda jika terjadi keterlambatan.

### 7. Halaman Denda

![Data Denda](gambar%20web/data%20denda.png)

Halaman denda menampilkan informasi denda yang harus dibayar siswa akibat keterlambatan pengembalian buku. Siswa dapat melakukan pembayaran denda melalui halaman ini.

### 8. Halaman Dashboard Siswa

![Dashboard Siswa](gambar%20web/dashboard%20sisswa.png)

Halaman dashboard siswa menampilkan informasi peminjaman yang sedang berlangsung, riwayat peminjaman, serta status denda. Siswa dapat dengan mudah mengakses fitur peminjaman dan pengembalian buku.
